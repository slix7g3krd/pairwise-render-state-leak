# pairwise-render-state-leak

同一帧里先画不透明再画特效，特效批次沿用了上一批的混合状态，整片粒子把背景盖成黑色；深度写入在预通道后没关，后续半透明物体互相遮挡；模板测试的参考值在批次之间没重置，描边越画越粗；裁剪矩形在上一个 UI 批次设置后再没恢复，3D 场景被裁成一个小方块；着色器程序切换时 uniform 缓冲没解绑，上一个材质的高光参数泄漏到下一个；顶点缓冲的偏移在实例化与非实例化之间复用，模型顶点错位；视口在渲染到纹理后没恢复，主画面被缩到左下角；光栅化状态里的剔除面在镜像相机之后没翻转，倒影只剩背面；颜色写掩码在后期通道被关掉，后面的 UI 完全不显示；多线程命令录制时状态栈没做线程局部，两个线程互相覆盖对方的混合模式。render/render_state_leak.py 是核心，tests/test_render_state_leak.py 15个红。要修的是：状态按批次显式设置；深度写按材质；模板值重置；裁剪栈保存恢复；uniform 按程序绑定；偏移按布局；视口栈；剔除随镜像；写掩码恢复；状态栈线程隔离。

## 运行

```bash
python -m pytest tests -q
```

初始状态：15 个用例失败。修复实现使全部用例通过，不要修改 `tests/` 下的测试。
